# note

个人学习库：计算机、土木工程（含 CAD/工程软件交叉）、数学、英语。

核心原则：**卡为主，题为练，笔记只做地图。**
目标不是「记全」，而是「能答出来」；所以主产物是闪卡，不是长笔记。

## 每天三件事

| 场景 | 动作 | 时间 |
|------|------|------|
| 学完当下 | 往 `收件箱/` 丢 1–3 条问题或卡点，不整理 | 1–2 分钟 |
| 每天 | 在 Obsidian 里复习到期卡；答错的记一行错因 | 10–15 分钟 |
| 每周 | 让 Claude 处理收件箱：它提问、你回答、答完才成卡 | 20–30 分钟 |

## 三条规则

1. **新知识先出卡，不写长笔记。** 一张卡只考一个点，30 秒内能答完。
2. **AI 先问，你答，才入库。** AI 只做提问、纠错、排版；你没答过的内容不写成卡。
3. **笔记是卡片攒出来的。** 同一主题 ≥5 张卡且容易混，才建一页地图，只放链接和一句话。

## 目录

| 目录 | 用途 |
|------|------|
| `收件箱/` | 一行一条的原始记录，一天一个文件，不做分类 |
| `闪卡/计算机/` | C#、CAD 二次开发、数据结构与算法、计算机基础 |
| `闪卡/土木/` | 力学、混凝土、钢结构、土力学、施工 |
| `闪卡/数学/`、`闪卡/英语/` | 数学、英语词汇 |
| `闪卡/旧卡/` | 从旧库迁来的按日期闪卡，继续复习，不强行重组 |
| `题目/` | 完整计算题、编程题和解题过程 |
| `地图/` | 专题地图（MOC），卡攒够后再建 |
| `templates/` | 收件箱、主题卡、题目的格式模板 |

## Obsidian 设置

1. 用 Obsidian 打开本文件夹作为 vault。
2. 安装并启用 **Spaced Repetition** 插件（旧卡的 `<!--SR:...-->` 复习进度会直接生效）。
3. 新建卡用「问题」+ 单独一行 `?` + 「答案」；单行卡可用 `问题::答案`。
4. 复习入口在命令面板里搜索 `Spaced Repetition`。

## 给 Claude 的入口

在 Claude Code 里可以直接说：

- `/capture`：把刚学到的内容丢进收件箱。
- `/learn`：提问式学习一个新主题，答完才成卡。
- `/quiz`：抽卡自测，一次一题。
- `/process-inbox`：每周处理收件箱，把答得出的内容转成卡。

> 首次创建技能后，重新打开一次 Claude Code 会话即可看到这些命令。

## 旧库

旧的 `Note` 库整体保留作归档，不迁移、不整理。只把 `flashcards/` 复制进来：

- `单词卡片.md`、`简写.md`、`中-英.md` → `闪卡/英语/`
- 按日期命名的旧卡 → `闪卡/旧卡/`

复习时如果觉得某张旧卡值得长期保留，再迁到对应主题文件；不要求一次性拆分。
