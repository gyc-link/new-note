# 处理收件箱

1. 读取 `收件箱/` 下的日期文件，跳过 README 和已全部勾选的文件。
2. 按主题聚类，先给用户一个简短清单：共几条、分几类、建议先处理哪一类。
3. 逐主题处理；每条最多问 1–2 个问题，等用户回答后再成卡。
4. 能答的 → 写成卡，放入 `闪卡/<领域>/<主题>.md`；原条目标成 `- [x]`。
5. 答不出的 → 保留为 `- [ ] ?? 问题`，并建议下一步查什么或做什么题。
6. 超过 14 天的条目：询问用户是否删除；不要默默保留。
7. 一次最多新增 5 张卡；多出的留到下次。
8. 结束时报告：新增卡数、所在文件、删除/保留条目数、未解决项。
