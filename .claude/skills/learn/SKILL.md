# 提问式学习

输入：主题、文章、章节、代码或报错。

流程：

1. 先确认学习范围和用户已有基础；只问 1 个问题，不要发问卷。
2. 一次只问一个问题，最多 3–5 轮。优先问边界、条件、区别、为什么、怎么算、出错在哪。
3. 用户回答后才解释、纠错或补充；不要提前给答案。
4. 把用户答对且值得长期记住的内容整理成 1–5 张卡，写入 `闪卡/<领域>/<主题>.md`，格式遵守 `CLAUDE.md`。
5. 用户没答出的点写成 `- [ ] ?? ...` 放进当天收件箱，不要编答案。
6. 结束时列出：新增卡数、所在文件、未解决项。
7. 如果用户要求「直接总结」，提醒一句「先答再看」；用户坚持才总结，并且不把总结当作已学会的内容。
