# 快速记录

把用户提供的内容追加到 `收件箱/YYYY-MM-DD.md`（今天的日期；文件不存在就创建）。

规则：

- 一行一条，保留用户原话；只做轻微断行，不改写、不补充、不解释。
- 不加主题标题、不建主题文件、不生成卡片。
- 代码、命令、报错放代码块。
- 如果内容是一组零散点，逐行记录即可。
- 完成后只回复：记到了哪个文件、共几条。

文件格式：

```markdown
# YYYY-MM-DD

- HH:MM 内容
```

今天的日期用系统日期，时间用 `date +%H:%M`。
