# 抽卡自测

1. 先问范围：计算机 / 土木 / 数学 / 英语 / 全部；默认优先到期卡。
   - 到期卡：卡片后的 `<!--SR:!YYYY-MM-DD,...-->` 中日期 ≤ 今天；没有 SR 元数据的卡视为未复习。
   - `闪卡/旧卡/` 也纳入范围，除非用户指定。
2. 一次只出一道题，只给问题，不给答案；等用户回答。
3. 回答后判定：对 / 部分对 / 错；指出缺失的条件或步骤，再展示原答案。
4. 答错时往当天收件箱追加一行：`- HH:MM 错因：……（题目：……）`。
5. 不手动修改 `<!--SR:...-->`；复习间隔由 Obsidian 插件负责。
6. 一轮 10–15 题或用户喊停；结束时只给简短统计，不生成学习总结。
