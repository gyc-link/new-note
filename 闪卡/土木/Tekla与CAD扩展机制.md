# Tekla 与 CAD 扩展机制

> 来源：2026-11-09 学习讨论「Tekla 插件与 AutoCAD 插件的进程模型」

Tekla 的 PluginBase 插件能跨进程运行吗？所谓「Tekla 可以跨进程」跨的是什么？
?
插件不能跨进程，由 Tekla 加载进自己的进程。
跨进程的是两个独立程序：Tekla 与外部应用（如 WPF exe），后者通过 Open API 连接正在运行的 Tekla。

进程外应用和进程内插件，能力差别的根源是什么？
?
通信方式决定可调用面：进程外只能调用宿主公开的 API 子集。
进程内代码直接跑在宿主里，能碰类型注册、序列化、绘制管线、命令管道等扩展点。
因此自定义实体这类扩展只能在进程内做；进程外做不了。
