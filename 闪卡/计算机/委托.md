# 委托

> 来源：2026-10-23 提问式学习（C# 委托）

C# 的委托是什么？它和它指向的方法需要满足什么条件？
?
委托是一种类型，表示对方法的引用；委托实例指向参数列表和返回类型都匹配的方法。
也可以先理解成「方法的类型」：它规定签名，具体方法按这个签名被传进来。
<!--SR:!2026-10-27,3,250-->

委托真正的优势是什么？为什么「非用委托不可」的场景其实很少？
?
优势是把一段行为当作参数或字段传递，不用为一次性逻辑专门建类。
LINQ、事件都能用别的方式实现，但用委托往往最轻。

委托和接口都能传递行为，实际怎么选？
?
传一个动作、一次性、无状态 → 委托。
传一组相关动作、要多实现/复用/带状态 → 接口。

写 `Retry(Action action, int times)` 时，为什么传动作用委托而不是接口？
?
传进去的只是「一个动作」；重试次数和失败状态属于 `Retry` 自身，不需要调用者提供一组方法。
动作若需要状态，用 lambda 捕获即可。
