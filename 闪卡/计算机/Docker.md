# Docker

> 来源：2026-10-24 提问式学习（用户基础：只听过名字，按教程跑过一个镜像）

Docker 容器和虚拟机最根本的区别是什么？
?
容器共享宿主内核，本质是宿主机上被隔离的普通进程（namespace 隔离、cgroups 限资源）。
虚拟机通过虚拟化层运行完整的 guest OS，有自己的内核，隔离更强但更重。

Linux 宿主机能直接运行 Windows 容器吗？为什么？
?
不能。容器里的程序直接调用宿主内核；Windows 程序需要 Windows 内核，Linux 内核不认这些调用。
Windows 上跑 Linux 容器，实际是先起一个 Linux 虚拟机（WSL2 或 Hyper-V）。

在容器里修改文件，会影响镜像吗？stop 和 rm 之后改动还在吗？
?
不会。镜像是只读模板；改动写入容器最上面的可写层（copy-on-write）。
stop 只停进程，可写层还在；rm 删除容器时可写层一起丢失。

删除容器后，volume 里的数据为什么还在？数据实际存在哪？
?
volume 的数据存在宿主机的磁盘上，不在容器可写层；删容器不影响，需显式删卷。
注意：是磁盘，不是物理内存（RAM 断电即丢）。
