# SSH 密钥

GitHub 上添加的 SSH 密钥，公钥和私钥分别放在哪？
?
公钥上传到服务器（GitHub/Gitee）；私钥只留在本机，不外传、不提交。

别人拿到了你的公钥，能冒充你登录你的仓库吗？为什么？
?
不能。服务器发一段随机数据，私钥签名、公钥验签；公钥推不出私钥，签不出应答。

错因：曾把 SSH 登录理解成「公钥和私钥配对」，没私钥只是「配不上」。
?
实际是挑战-应答：服务器发随机数据 → 本机用私钥签名 → 服务器用公钥验签。

错因：曾认为公钥转换后不变是因为「它已经在服务器上，不受我们控制」。
?
转换全在本地做。不变的原因是只换了文件封装，私钥数学内容没变，公钥由它算出。格式 ≠ 密钥。

私钥 `.ppk` 为什么不能直接给 Git 用？
?
`.ppk` 是 PuTTY 的封装格式，Git 自带的 OpenSSH 认不出。同一把密钥只需换封装：PuTTYgen → Conversions → Export OpenSSH key。
